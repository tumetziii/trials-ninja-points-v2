How much is a level 8 worth?

The points system turns every PC leaderboard run on ninja levels 7–9 into a rider rating. Levels 1–7 sit on a smooth curve. Past level 7, the values are set by hand. Those values are opinions, so I'd like yours. Answer the questions below by number, then use the scenarios and sandbox to see what each answer does to the top 20.

Part 1

Questions

"Average pass" means a run with the typical fault count and time for that level: about 110 faults and 20–24 minutes. Level worth is a multiplier on that average pass.

Level worth

1
How many average level 7 passes is one average level 8 pass worth?
Now 13×, set by judgement. Passer counts would say 2.47× (111 riders have a level 7, 45 have a level 8). If the level 1–7 curve just kept going it would be 1.26×. The scenarios test 1.26× to 20×.
2
How many average level 8 passes is one average level 9 pass worth?
Now 20×, set by judgement. Passer counts would say 5.6× (45 riders vs 8). Together with Q1, the current setting makes one level 9 worth 260 level 7s.
3
Should level worth come from how few people have passed it, from how hard riders think it is, or a mix?
Both levels use judgement today. Rarity is objective but rewards levels that are under-played as well as hard. The passer counts include padding for riders missing from PC boards: level 7 is 81 PC riders plus 30 for console and pre-2020 passes, level 8 is 42 plus 3, level 9 is 8 with none. If you prefer rarity, do those counts look right?
4
One level 9 pass vs a deep level 8 list: who should rank higher?
PennyJX has 17 L7, 21 L8 and 1 L9 runs. [C] Scottah- has 19 L7 and 50 L8 runs and no L9. The current model puts Penny 8th and Scottah 9th. The rarity-only model puts Scottah 8th and Penny 10th. Which order feels right?
5
How much should a big level 7 list count against fewer, harder passes?
Danimalls has 109 L7 and 30 L8 runs. Skilbobaggins has 17 L7 and 13 L8. They sit 11th and 14th now. Extending the curve pushes Danimalls to 5th and Skilbobaggins to 17th.

Tracks within a level

6
Should every track in a level be worth the same?
Right now every level 8 track has the same base worth. Faults and time are compared to the level average, not the track average, so a run on an easier track also scores better on faults.
7
Should checkpoint variants (+CPs, ++CPs) count as full separate tracks?
Many level 8 tracks have checkpoint variants. They are currently scored as separate tracks at full level 8 worth, so one layout can earn points more than once.

Other inputs

8
How much should faults matter?
A 0-fault run is worth about 3× an average pass on the same level, including a 1.15× bonus for a clean run. A 300-fault run is worth about 0.7×. With level 8 at 13×, a 0-fault level 7 is worth about a quarter of an average level 8. Too generous, too stingy, or about right?
9
Depth or peak?
A rider's best 100 runs count, each worth 95% of the one before. So the 14th-best run counts half, and the 45th about a tenth. Should more runs count, or fewer?
10
How much should time matter?
Time can move a run's score by at most ±10%. It is kept weak because faster runs usually also have fewer faults, which already scores.
